# PRIMEngine: notes for Claude

- Owner (Kiru) does not code; they direct, make art/audio and test. Explain in plain English; do the coding.
- Plain classic `<script>` files on a global `PRIM` namespace. No bundler, no ES modules, no third-party libs.
- `index.html` is PRIMEngine Studio (project manager + screen editor). `legacy-editor.html` is the old Metroid-style test editor (still works, uses src/engine, src/game, src/editor).
- Studio: EVERY value is a tag (`src/core/tags.js`), named `screen.element.property` or `audio.master`. Structure (screens, element ids) is separate from values. Renaming an element moves its tags and fixes references.
- Project file = `.prime` (a ZIP: project.json + Assets/ folders), see `src/core/prime.js`, `zip.js`. Browser autosave copy lives in localStorage; imported files in IndexedDB (`src/core/store.js`). `src/core/host.js` handles save/open/pick-folder (Electron via `window.primeDesktop`, else File System Access API with download/<input> fallbacks).
- Maps (`project.maps`) are GRID maps (EasyFPS style, `src/core/grid.js` = `PRIM.Grid`): `{id, style:"grid", w, h, layers:[{cells:{"x,y":cell}}], things, n}`. One cell = 128 units = 2 m, one layer (story) = 128 units tall. Cell keys: `w` wall block texture ("" = default look, `ws:{0..3}` per-side textures, 0 N 1 E 2 S 3 W), `f` floor texture + `h` 0..15 (16ths, 8 units each), `sh` "slope"|"stairs" + `sd` rise direction + `sr` rise 1..16 (stairs = 8 steps), `c` ceiling (at layer top - 1), `li` light %, `dg` diagonal/partial wall = solid polygon [[u,v]...] in the cell (0..1, u east, v south) + `dt` its texture (`G.SHAPES`: 45°, 26° (2 cells), 18° (3 cells), 63°, small/big corner cut, half block, edge wall; `G.shapeCells(id, rot, flip)`; built as a prism, info kind "diag"). Cells are STRUCTURE (not tags); map settings are tags (`Schema.MAP`: sky, fogOn/fogColor/fogStart/fogEnd, mood preset (`R3D.MOODS`) or custom moodTint/Brightness/Contrast/Saturation, startX/startY/startLayer/startAngle). World: X = x*128, Z = y*128, Y up. Old room/node maps are deleted on load (`ensureWalls`, owner: start fresh); the Wall Editor, wallmesh.js and mapgeo.js are gone.
- Screens are drawn by `src/core/runtime.js` (DOM, 1280x720 stage). Studio UI (`src/studio/studio.js`, CSS in index.html) copies classic Unity: Hierarchy, Scene/Game, Inspector (+Tags), Project explorer, Console; skins `dark` / `light`.

- Renderer: `render3d.js` `rebuild` = `Grid.build(map)` (batches per texture x 8x8-cell chunk, frustum culled via `visible()`) + `Grid.index(tris)` -> `View.world`; `View.raycast` = `Grid.raycast` (DDA over 256-unit cells) + `View.extraTris` (closed doors). Sub-steps: sideways <= 0.6 r, vertical <= 0.25 r (else the narrow head tunnels through ceilings when jumping). Upper-story floors get a hidden downward collision face (info.hidden: collision only) when nothing is under them. Max walkable slope cos 0.69 (a full 16/16 slope = 45 deg).
