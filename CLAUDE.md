# PRIMEngine: notes for Claude

- Owner (Kiru) does not code; they direct, make art/audio and test. Explain in plain English; do the coding.
- Plain classic `<script>` files on a global `PRIM` namespace. No bundler, no ES modules, no third-party libs.
- `index.html` is PRIMEngine Studio (project manager + screen editor). `legacy-editor.html` is the old Metroid-style test editor (still works, uses src/engine, src/game, src/editor).
- Studio: EVERY value is a tag (`src/core/tags.js`), named `screen.element.property` or `audio.master`. Structure (screens, element ids) is separate from values. Renaming an element moves its tags and fixes references.
- Project file = `.prime` (a ZIP: project.json + Assets/ folders), see `src/core/prime.js`, `zip.js`. Browser autosave copy lives in localStorage; imported files in IndexedDB (`src/core/store.js`). `src/core/host.js` handles save/open/pick-folder (Electron via `window.primeDesktop`, else File System Access API with download/<input> fallbacks).
- Maps (`project.maps`, format still 3): geometry is structure (`verts`, `sectors` = closed loops of vertex ids); every other value is a tag (`map1.s1.floor`, `map1.v3.tex` = texture of the wall running from node v3 to the next node of its room). Editor styles: `doom` (built, `src/studio/mapeditor.js`), `modern` (locked in the New Map dialog, comes later). 3D renderer = `src/core/render3d.js` (WebGL1, free-fly camera). Game Play action `start` launches the first map in the fly view for now.
- Screens are drawn by `src/core/runtime.js` (DOM, 1280x720 stage). Studio UI (`src/studio/studio.js`, CSS in index.html) copies classic Unity: Hierarchy, Scene/Game, Inspector (+Tags), Project explorer, Console; skins `dark` / `light`.
- TARGET IS WINDOWS ONLY for now (owner decision). Mac/Linux builds come after the Windows app is finished; do not spend time on them.
- Desktop app: `desktop/` (Electron). Built on GitHub by `.github/workflows/build-desktop.yml` (push to main = Actions artifacts; tag `v*` = Release). npm is NOT reachable from the Claude sandbox, so desktop builds can't be tested locally.
- Never commit `projects/*/assets/` (private / fan-game material). Never draw or invent Nintendo characters, creatures or logos; placeholders must be original.
- Never write `*/` inside a block comment (it ended one early once).
- Test studio: serve repo root on :8766, `NODE_PATH=$(npm root -g) node tools/dev/shot3.js <out> tools/dev/s_unity.js` (removes File System Access APIs to test fallbacks). Legacy editor: `tools/dev/shot.js` + `s_editor.js` (needs software GL). Map test: `tools/dev/s_map.js` through shot3.js (shot3 launches Chromium with SwiftShader so WebGL works).
- Publishing: `python3 tools/build_single.py` (add `legacy-editor.html` for the old one), then publish `dist/index.html` as an artifact (Studio needs no supporting files).
- Player (`project.player`, tags `player.*`; schema in `schema.js` S.PLAYER/S.ATTACH): walking/collision/jump/sprint/crosshair/aim modes (classic, free = bodycam) in `src/core/play3d.js`; HUD = a screen of kind `hud` drawn over the game. Player Editor tab attaches FBX models to the camera (`player.att1.*` tags); a weapon has a muzzle point + arrow that turns toward the crosshair raycast.
- FBX: `src/core/fbx.js` (ASCII + binary, rigid node animation only, no skin weights), math in `math3d.js`. Timeline tab: sound events per model animation, stored as `project.events=[{id,asset,anim}]` + tags `ev1.time/sound/volume`; played by `Play3D.ev()` in game.
- Tests: `tools/dev/s_att.js` (attach/aim), `s_tl.js` (timeline + in-game sounds), `s_player.js`, `s_map.js`, `s_unity.js`.
- Screen positions (`x`,`y` tags of screen elements) are measured from the MIDDLE of the 1280x720 stage (x0,y0 = middle, y up). `project.origin==="center"`; `Schema.toCenter` converts older projects in `Store.migrate`. Edit mode in runtime.js has a corner resize handle (`rt-handle`) and the inspector has Center buttons.
- Player objects (`project.player.attachments`, tags `player.<attN>.*`) have a `type` tag: weapon (numbered weapon list, 1-9 / wheel switch, muzzle + arrow), animation (FBX model) or image (flat quad via `FBX.loadImage`). Object editor = `objectCenter()` in studio.js (click to place muzzle, drag to aim arrow).
- Hierarchy folders: `project.hfolders=[{id,name,scope?}]`, items carry `.folder`; scope = a screen id means a folder of that screen's elements.
- Tests also: `s_obj.js` (objects, weapon switch), `s_fold.js` (folders), `s_hud.js` (origin, resize handle, migration).
- Node Coder (tab "Node Coder"): one script per object, stored on it as `script={nodes:[{id,type,x,y}],links:[{a,o,b}]}` (screen element nodes and `project.player.attachments`). Node values are tags `<owner key>.s.<nodeId>.<value>` (owner key = `screen.element` or `player.attN`). Node types live in `Schema.SNODES`; runner = `src/core/script.js` (`PRIM.Script.Host`, async chains with wait/if/repeat). Hooks: `Runtime.script()` for screens (onStart/onClick/onKey), `Play3D.trigger()` for player objects (onStart/onClick/onKey/onEquip; a weapon only hears events while it is the current weapon). The old per-weapon "click animation" tag was replaced by a script (`ensurePlayer` migrates it). UI = `coderCenter()` in studio.js.
- Objects have a free pivot (`pivotX/Y/Z`, model space): position, rotation and scale act around it; set it with the "Set pivot" tool of the object editor.
- Tests also: `s_code.js` (node coder).
- Asset explorer multi-select (`studio.js`): `S.sel` is the primary item, `S.multi={primary,items}` the set (ctrl/shift-click via `clickPick`, rubber-band via `marquee`, `topLevel()` drops items inside a selected folder); multi drag/drop uses `dropOne`, delete uses `deleteAssetSel`. Tests: `s_multi.js`, `s_size.js` (width/height fields, proportions, corner handles).
- Game view (`Play3D.bind`) has a `.p3leave` button shown whenever the mouse is free. Images have a `stretch` tag ("Stretch to screen", fills the 1280x720 stage). Tests: `s_stretch.js`, `s_leave.js`.
- Keys: `Schema.KEYS` (dropdown list incl. mouse1/2/3 = left/right/middle). Node types onKey, onKeyUp, onHold (interval), ifKey; hold/up/ifKey are player-object only. Play3D: `press/release/hold`, player sound tags (footstep*, jumpSound, landSound, hurtSound, deathSound, soundVolume). Tests: `s_input.js`, `s_input2.js`.
- Weapons: projectile settings (`projType` none/hitscan/particle/mesh, `proj*` tags) and a projectile emitter point+arrow (`emitX/Y/Z`, `emitYaw/Pitch`, object editor tools "Set projectile emitter"/"Aim emitter arrow"). Nodes `onCharge` (shown as "Charge weapon"; outs start/charged/fire/cancel; `Play3D.charge`, live tag `player.charge`) , `chargeShow` + `chargeGrow` (charge particle at the emitter, `Play3D.orb`; the released projectile keeps its size) and `fireProjectile` (`Play3D.fireProj`, FX drawn by `View.drawFx`). Node Coder: Shift+A opens the add menu (`S.coderMenu`), categories are submenus (`menuEl` supports `sub`). Test: `s_charge.js`.
- Timeline: animation length overrides `project.animLen=[{id,asset,anim}]` + tag `<id>.length` (`Schema.animLen`, `Play3D.animLen`; sound times are in the adjusted seconds; orange handle drags the length); sounds are bars with waveform (`waveOf`), Shift+drag / wheel = volume. Test: `s_len.js`.
- Player feel: tags `player.breathe*`, `bob*`, `hudMove`/`hudMoveAmount` (`Play3D.feel`: viewmodel offset `vmOff` + HUD sway via hudHost transform); player state (standing/walking/running/jumping/falling, groups moving/inair) = live tag `player.state`, nodes `onState` + `ifState` (`Schema.STATES`, `Play3D.setState/isState`). Test: `s_feel.js`.
- Renderer upgrade: lights + materials + culling + auto-LOD. `render3d.js` fragment shader takes up to 8 lights (point, or area = flat rectangle panel) and a material (`setMat`: tint, emit, lit, alpha, spec); `setLights(list)` is fed by Play3D each frame (`lightPrev` for the world pass, `lightNow` for fx + viewmodel; items `{p,r,c,type,n,u,hw,hh}`), `useLights(camSpace)` converts for the viewmodel pass. Object tags (ATTACH fields with `tab:"light"` / `tab:"material"`, shown in the inspector tab strip Object/Material/Light via `S.objTab`): `lightType/Color/Intensity/Range/Flicker/X/Y/Z/Width/Height/Yaw/Pitch`, `matTint/matEmit/matEmitColor/matLit/matOpacity/matShine` (`Schema.matOf`). Projectile tags `projEmit` (glow), `projLight/projLightPower/projLightRange`. Object editor tools "Set light point" / "Aim light" (gizmo + live preview in the editor).
- Culling: map geometry is built as chunks per sector x texture with AABBs; `View.visible()` = frustum test + rooms reachable through open walls (`this.adj`); tag `gfx.culling`. Auto-LOD (`gfx.lod`): `View.lodOf` vertex-clustering (lazy), `lodLevelAt(dist,size)`, used for projectile meshes only (viewmodel stays full detail). `View.stats` shown by `Play3D.stats3d` when `gfx.showFps`. Tests: `s_light.js`, `s_cull.js`.
- Scale: 32 units = 1 tile = 0.5 m (64 units = 1 m). Defaults: eye height 102, room ceiling 192 (3 m). Map editor shows meters. `Schema.ensureWalls` heals older projects (eye 56 -> 102 once, flag `project.eyeMoved`).
- Wall types (tab "Wall Editor", `src/studio/walleditor.js` = `PRIM.WallEditor`, data `src/core/wallmesh.js` = `PRIM.WallMesh`): `project.walls=[{id,name,n,verts:[{id,x,y,z}],faces:[{id,v:[...]}]}]`, face values are tags `<wall>.<face>.tex/.color`. One panel = 96 x 96 units (1.5 m); panel space x along wall, y up, z out of the wall into the room. Tools: select/move/extrude/inset (drag, modal with undo snapshots `W.snap/restore`), cut (quads, `W.cut`), delete, face/vertex mode; keys Q G E I X 1 2 A F Ctrl+Z. Maps: edge tags `map.vN.rows` ("wallA,wallB", bottom to top, each row = 1.5 m of panels, `rowsRepeat` repeats the top one); `render3d.js rebuild` cuts the wall into panels (a plain wall is kept 1 unit behind). Map inspector has "Wall layers". `View.setBatches` draws raw triangles (used by the Wall Editor). Tests: `s_wall.js`, `s_wallmap.js`.
- Audio nodes: `loopSound` / `stopLoop` (Script host callbacks `loop` / `stopLoop`; Runtime + Play3D keep one looping Audio per sound, stopped on destroy). Test: `s_loop.js`.
- Objects (tab "Object Editor", `propCenter()`/`propInspector()` in studio.js): `project.props=[{id}]`, schema `Schema.PROP` (tags `<propId>.name/type/asset/scale/rx..oz/idleAnim`, door: `doorWidth/doorHeight/openMode(interact|proximity|shot)/openRange/interactRange/openAnim/closeAnim/autoClose/closeAfter/openSound/closeSound`, pickup: `giveTag/giveAmount/pickRadius/pickSound`). Type = decoration / door / pickup. Editor shows a 3x3 tile (1.5 m) ground grid, doorway rectangle and wall-thickness box; "Scale to grid" / "Center on grid".
- Placed objects live in `map.things`: door `{id,prop,sec,a,t}` (sits in the wall from node a to the next node of room sec, t = 0..1 along it), others `{id,prop,x,y,ang}`. Map editor tool "Place Object" (key O) + selecting/dragging/deleting things; inspector branch for sel.kind "thing". Maps have tag `mapN.wallThickness` (16 units = 0.25 m); `R3D.thingFrame` gives position/orientation; render3d cuts the doorway (jambs/lintel/threshold) and keeps door edges in portals. `player.interactKey` (default E).
- Runtime: `Play3D.syncThings/thingStep/drawThings` (door state machine closed/opening/open/closing, FBX openAnim/closeAnim or slide-up fallback, `hitDoor`/`shootDoor` for shot mode (hitscan + projectiles), `interact()`, proximity, autoClose; `doorOpen` makes `push` ignore the door wall segment; pickups add `giveAmount` to tag `giveTag`). Tests: `s_door.js`, `s_place.js`.
- Rooms touching/overlapping: `src/core/mapgeo.js` (`PRIM.MapGeo.addRoom` used by Draw Room): a new room is cut (polygon difference) so it never overlaps an existing room, then `stitch` splits walls where another room's node lands on them. Rooms keep their own nodes; a shared wall is recognised by POSITION (`render3d.js ekey` uses node coordinates, `R.openKeys` = walls open on either side, `sameP`). Doors on shared walls cut both sides. Refused: a room fully inside another or fully surrounding one. Tests: `s_rooms.js`, `s_conn.js`.
- Fly Editor (tab "Fly Editor"): `View.editMode` = hold RIGHT mouse + WASD to fly, left-click picks a face (`View.rayAt`, `raycast` returns `info` {kind wall|floor|ceil, sec, vert} from `triInfo`), Shift adds, hover outline; selection `S.fsl`, outline drawn through `View.overlay` (drawFx lines), `flyInspector()` sets texture/colour of all selected faces (tags `mapN.vX.tex/color`, `mapN.sN.floorTex/ceilTex/...Color`), images can be dropped on a face (`flyDrop`). Fullscreen fly keeps the old behaviour. Test: `s_fly.js`.

- HUD (rebuilt; runtime.js no longer draws HUD screens): game renderer `src/core/hud.js` = `PRIM.HUD` ({host,project,tags,urls,screenId,edit,onUpdate}); NOTHING clips, elements hang off the host middle, each scaled by min(w/1280,h/720) around its own middle; one container so layer order = element order; "Stretch to screen" images are sized to the host + max sway (70x50 per hudMoveAmount) on every side; `sway(x,y)` (called by `Play3D.feel`). Editor `src/studio/hudeditor.js` = `PRIM.HudEditor` (uses PRIM.HUD inside a pan/zoom view: wheel zoom, middle/right/Space drag pan, F fit, dashed 1280x720 standing-still frame, dotted sway frame, select/move/corner resize `.hed-h`, arrows nudge, `dropPoint(e)` for dropped images). Studio `hudCenter()` picks it for screens of kind hud (Game tab shows PRIM.HUD). Test: `s_hud2.js` (also `s_hud.js`).- Audio engine (rebuilt): `src/core/audio.js` = `PRIM.Audio` (Web Audio). `load(url)` decodes once (cache) and finds the real sound inside the file (skips encoder silence at start/end, <= 0.3 s, below ~-60 dB); `play(url, vol, loop)` -> handle {stop(fade), setVolume(v), playing}; loops are sample-exact (`loopStart/loopEnd` = trimmed part). Falls back to <audio> if decoding fails. Used by runtime.js (sfx, loops, music), play3d.js (`vol3`, `sfx`, `loopSfx`, timeline events; preloads all sounds at start), hud.js and Studio previews. Tests hook `PRIM.Audio.play` (`s_audio.js`, `s_loop.js`, `s_tl.js`).
- Gameplay (objects): Object types `enemy` (tags health/speed/radius/height/sight/attack melee|hitscan|projectile/attackRange/damage/attackRate/attackDelay/proj*/walkAnim/attackAnim/hurtAnim/deathAnim/corpse/sounds/killTag/killAmount) and `exit` (exitTo map|screen, exitMap (type `mapRef`, empty = next map), exitScreen, exitRadius, exitSound). Play3D: `enemyStep` (idle -> sees you (canSee raycast, 5 Hz) -> chase (ePush walls/doors/enemies) -> attack (eAttack) / pain / dying / dead), `hitEnemy` (cylinder ray) + `damageEnemy`, weapon damage tag `projDamage` (fx carry `dmg`, enemy fx `hostile`), `hurtPlayer`, red `flash`, `deathStep` (player.deathAction restart|screen, deathDelay, `restartMap`), `levelExit` -> `loadMap(id)` (keeps health/ammo) or `o.onScreen(id)`; enemies push the player. Play mode only rebuilds the map when map/wall/prop tags change.
- Ammo: weapon tags `ammoUse/ammoStart/ammoMax/clipSize/reloadTime/reloadAnim/reloadSound/emptySound`, live tags `player.<att>.ammo` (ready) and `.reserve` (fields with `live:true` are hidden in the inspector). `initAmmo/useAmmo/reload/reloadStep/ammoClamp`; `player.reloadKey` (default R); script nodes `reload`, `ifAmmo`. Player "Game rules": startMap, deathAction/deathScreen/deathDelay, reloadKey, damageFlash. Tests: `s_enemy.js`, `s_ammo.js`.
- Animation Editor (tab "Animation Editor"): `src/studio/animeditor.js` = `PRIM.AnimEditor` (viewport: Q orbit / G move in camera plane via `M4.inv` / R rotate X Y Z / S scale, click picks a part by its screen box; timeline canvas: rows = model nodes, diamonds = keys, scrub, drag keys (1/30 s snap, Shift free), dbl-click adds, Delete/X removes, K keys, Space plays, Ctrl+Z/Y). Data `project.anims=[{id,asset,name,dur,keys:[{node,t,p,r,s}]}]` (structure, not tags); `src/core/animlib.js` = `PRIM.AnimLib` (`build/apply/applyAll/valueAt/setKey/removeKey/fromModel`) turns them into normal model animations (`model.anims[name]` with `custom:id`), applied when a model loads via `PRIM.FBX.decorate` (set in Studio `loadModels`). Renaming fixes anim tags and Timeline events. Studio: `animCenter()/animInspector()`. Test: `s_anim.js`.
